# Finding Consensus from AI Alignment Studies: A Short Survey

This project surveys existing AI alignment studies to identify where different approaches agree and disagree about how to keep advanced AI systems aligned with human values, preferences, and goals, across two categories: human–AI and brain–AI representational alignment studies.
